# Dead Letter Auditor — optional Kiro Crew app

This folder is a **starter** for the **Best Kiro Crew App** bonus prize
($1,000). It is *not* part of the main submission and is not claimed as working
until Jayant verifies it against the current Crew App Kit docs.

## To make it eligible
1. Read https://kiro.dev/docs/crew/apps/ and the manifest reference. **Validate
   every field in `app.json`** — the App Kit evolves quickly and this manifest is
   intentionally minimal. Add a dashboard page (`ui/`) if you want the app to
   appear in the sidebar; a Skill-only app may be acceptable with fewer fields.
2. Publish this folder as a **separate public GitHub repository** under the
   same GitHub account as the main submission (the rules require a separate Crew
   app repo whose GitHub account matches).
3. Install it in Kiro Crew with `kirocrew app install` and verify it runs.
4. Add a short write-up of its features/functionality plus the public repo URL
   to the Devpost submission form.
5. Log the real Crew session in `docs/KIRO_EVIDENCE.md`.

## Honesty note
If you do not complete steps 1–5, **do not tick Best Kiro Crew App** on Devpost.
An unverified extra prize claim is worse than no claim.
