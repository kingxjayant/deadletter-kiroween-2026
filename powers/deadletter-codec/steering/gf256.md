# GF(2^8) and the MDS guarantee

## Field
Polynomial `0x11D` (AES), generator 2. `EXP[i] = 2^i mod P` for i in 0..254,
repeated into `EXP[255..511]`; `LOG[EXP[i]] = i`.

- `gfMul(a,b) = a===0||b===0 ? 0 : EXP[LOG[a] + LOG[b]]`
- `gfInv(a) = EXP[255 − LOG[a]]`, `gfInv(0)` throws
- Addition is XOR; subtraction is the same operation.

## Generator matrix
`G = [ I_k ; C ]`, `C` is `(n−k) × k`:

```
C[i][j] = gfInv( x_i XOR y_j )
x_i = i                 (0 .. n−k−1)
y_j = (n−k) + j         (n−k .. n−1)
```

`x` and `y` are disjoint integer sets, so `x_i XOR y_j != 0` and the inverse
exists. A Cauchy matrix is *super-regular*: every square submatrix is
nonsingular. Stacking identity rows preserves that property, so every choice of
k rows from the n rows of G is invertible. That is the MDS property: **any k
strips, not just the first k**, reconstruct all k source chunks.

## Decoding
Given k received tiles with indices `S`, build the k×k matrix A whose rows are
unit vectors for systematic tiles and Cauchy coefficient vectors for parity
tiles. Compute `A⁻¹` by Gauss–Jordan with an augmented identity. Then
`source = A⁻¹ × receivedChunks`, concatenating the k chunks and trimming to the
true byte length stored in every header.

## Worked example (k=8, n=14, n−k=6)
- `C[0][0] = gfInv(0 XOR 6) = gfInv(6)`
- `C[5][7] = gfInv(5 XOR 13) = gfInv(8)`
- Tiles 0..7 are data; tiles 8..13 are parity.
- Destroy strips 0, 3, 5, 9, 11, 12 → solve with the remaining 8 → exact message.

## Verification, not proof-by-test
`tests/pbt.test.mjs` supplies evidence (hundreds of generated messages and
subsets). The mathematical guarantee comes from the super-regularity of Cauchy
matrices. Kiro's spec "Correctness" PBT feature generates the same style of
check from EARS requirements; record its real output in `docs/KIRO_EVIDENCE.md`.
