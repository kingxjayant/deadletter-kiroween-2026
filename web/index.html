The telegram is dead. Long live the telegram.

In flood-prone districts, disaster zones, shuttered networks and villages with one bar of 2G, the cloud is a rumour. DEAD LETTER resurrects the 19th-century paper tape: your message becomes a strip of QR-coded tiles with a human-readable telegram fallback. A systematic Cauchy Reed–Solomon code means {{K}} of {{N}} strips rebuild the whole message — even if the rest are torn, stained or never arrive.

Why paper?

  1. Print or photograph. A cybercafé printer, a phone screen, a photocopy — any surface works.
  2. Carry it. Someone else scans the strips with their camera, or types the telegram letters if a QR is ruined.
  3. Lose some. Rain, torn corners, a missing page — the code only needs k strips.
  4. Verify. A SHA-256 fingerprint proves the resurrected message is byte-for-byte the original.
G = [ Ik ; C(n−k)×k ] Cauchy matrix over GF(2⁸) → MDS → any k rows invertible

A real audience
ASHA workers, rural teachers and volunteers in Bihar/Jharkhand move paper between connected and disconnected places every day. They have a printer and a phone camera, not a backend.

      
02
A resurrected medium
Telegraph paper tape carried the world's messages before the network existed. We revived it with error-correcting maths instead of copper wire.

      
03
A haunted interface
Torn strips go translucent, the resurrection meter drains, and the verdict is stamped in phosphor. Every spooky effect reports real state.
